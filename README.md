# Full-Stack Chat Application
A production-ready, full-stack real-time chat application built with React, Node.js, Express, Supabase (PostgreSQL), and Socket.io.

# Features
- Real-Time Messaging: Instant message delivery and low-latency communication powered by Socket.io.
- Authentication & Database: Secure user management and persistent storage using PostgreSQL via Supabase.
- Presence Indicators: Live user online/offline status tracking.


# Tech Stack
- Frontend: React, React Router, CSS
- Backend: Node.js, Express.js
- Real-Time: Socket.io
- Database & Auth: PostgreSQL (Supabase)
- Version Control: Git
